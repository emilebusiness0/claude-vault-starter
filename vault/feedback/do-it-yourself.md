# Do it, don't hand it off

*Index: [[README]]*

- **Never make a terminal command the thing {{NAME}} has to do.** If Claude can run it, Claude runs it.
- **When a step really is {{NAME}}'s, give it as numbered clicks.** Where to go, what to click, what it should look like after.
- **Never remove or undo work that is already good.** Improve it in place.
- Never leave something half done to "do later" when it can be finished now.

**Why:** the whole point is to save {{NAME}} time. Handing back copy-paste work spends it.
