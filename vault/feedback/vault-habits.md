# Vault habits

*Index: [[README]]*

- **Read DECISIONS.md before choosing a tool, a platform, a price or a plan.** If the question is already answered there, apply the answer. If it is new, add one row the same turn.
- **If something is useful later, write it to the vault right away, without being asked.** A fact {{NAME}} shares, a preference, a decision, a correction. In the note that owns the topic, not a new note each time.
- **A new fact is saved only when the old one is gone.** When something changes, search for the old fact before writing anything. Fix every hit in the same turn, then add the old wording as a row in RETRACTED.md.
- **Link what you cite.** Another note is a `[[folder/name]]` link, so nothing floats alone.
- **A note read whole stays under 3,000 words.** Past that, the dated story moves into `<note>-history.md` and the note is rewritten as what is true now.

**Why:** a vault that only grows looks exactly like one that learns, for months. Only one of them changes what Claude does. The hooks check most of this at the end of every turn.
