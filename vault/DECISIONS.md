# Decisions

*Index: [[README]]*

**Read this before choosing anything.** Find the question in its area file. If it is there, apply the answer.

## How to keep it honest

- **A new decision is one row in its area file, in the same turn it is made:** the question, the answer in about 60 words (the decision and every "never" or "always" with it), the date, and a link to the note with the reasoning.
- **A superseded decision is struck through (`~~like this~~`), never deleted,** and the new row is added under it. Two live answers to one question is worse than none.
- **A decision with no link is not finished.** If the reasoning is not written down somewhere, write it first.
- **A table cell cannot hold a raw `|`:** write `\|`.
