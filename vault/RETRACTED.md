# Retracted facts

*Index: [[README]] · the rule: [[feedback/vault-habits]]*

A correction is not finished when the notes you thought of are fixed. It is finished when the dead claim is written down here, in the words it actually appeared in, and nothing in the vault still says it.

## How to use it

- **The phrase is what to hunt for**, lowercase, matched as plain text. Add every wording the dead fact wore.
- **Only a table row is read.** One dead phrase per row, alone inside one pair of backticks. A prose list is invisible to the check.
- A note **may** still contain the phrase when the same line marks it as dead: struck through with `~~`, or saying "retracted", "corrected", "no longer", "used to", "superseded".
- Never delete a row.
- The end-of-turn check adds rows here itself when a save names what it replaced.
